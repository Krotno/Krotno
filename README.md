### 🧑‍💻 About me

I build cross-platform apps in **C#** and then keep them company with the infrastructure they live on. Days usually split between **.NET MAUI** and **WPF** on the client, and a homelab on **Proxmox** and **Docker** behind that: a private cloud, throwaway test VMs, Git, a VPN, and Nextcloud. If it can be self-hosted, it probably already is, or it is next on the list. 📦

Local AI is not a demo tab I open once. **Ollama** and other on-prem models get wired into real products, so the weights and the chat history stay on the network and never need a cloud account to say hello. The dedicated card for that job is an **NVIDIA CMP 90HX**. The picture on the desk is a completely different GPU. More on that below, because the machine is half the hobby. 🤖

I am putting a public portfolio together and looking for a start in Europe. New tools stick quickly, hard bugs are more interesting than easy tickets, and a messy log is just a conversation I have not finished yet. Open to collaboration, code review, and any role that mixes app development with infrastructure. 🌍

### 🖥️ The desk

This is a dual-socket workstation, not a laptop with RGB. Two server CPUs, a pile of RAM, one GPU for the pixels, and one GPU that never has to draw a single frame. ⚡

| | |
| --- | --- |
| 🧠 **CPUs** | 2× Intel Xeon E5-2686 v4. Eighteen cores and thirty-six threads each, so the box shows up as **36 cores / 72 threads**. |
| 🧩 **Board** | X99-8D4/2.5G Server. Dual socket, with 2.5G networking on the board. |
| 🧮 **Memory** | **128 GB** RAM. Enough to keep a few VMs, an IDE, and a local model from fighting over the same sticks. |
| 🎮 **Display GPU** | AMD Radeon RX 6900 XT. This one owns the monitors. |
| 🤖 **AI GPU** | NVIDIA CMP 90HX. A 10 GB GDDR6X compute card with no display outputs, parked here so Ollama has its own silicon. |
| 🖵 **Monitors** | Titan Army C49SH, a 49-inch 32:9 super ultrawide, plus two matching LG UltraWide 29U511A-B panels (29-inch, 2560×1080, IPS, 100 Hz). |

Three ultrawides on one desk sounds excessive until a MAUI layout, a Proxmox console, and a model log all want to be visible at once. Then it sounds like the minimum. 😅
