I build cross-platform apps in C# and run the infrastructure they live on. Most of my time goes into **.NET MAUI** and **WPF** on the client, and into a homelab on **Proxmox** and **Docker** behind that: private cloud, test VMs, Git, VPN, and Nextcloud.

I also wire **local LLMs** (Ollama) into real products, so the model stays on the network and the chat history never has to leave it. I am putting a public portfolio together and looking for a start in Europe. I pick up new tools quickly, and I like hard bugs more than easy tickets.
